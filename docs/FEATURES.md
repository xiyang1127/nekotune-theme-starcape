# 星穹 · Starcape 主题

将 NekoTune 的 `feat/starcape-ui-redesign` 分支（`46b00fa`）独立为 QML 主题。保留星辉蓝配色、图标导航栏、悬浮播放胶囊、首页卡片、曲库列表／封面网格、分组设置和星座空状态，增加对应浅色配色。

主题 ID 为 `nekotune.theme-starcape/default`，版本 `1.1.1`。它通过 `ui.shell` 替换窗口内容，通过 `ui.wallpaper` 提供星空音乐壁纸，没有后台代码、服务或扩展依赖。播放、队列、歌单、曲库和设置继续使用宿主控制器；切换主题不重新创建这些控制器。主题中的 `Theme.qml` 读取 `ExtensionApi.theme`，只有导航栏／胶囊等私有布局尺寸保留在包内。

## 安装

使用支持 `ThemeController` 和 `.nktheme.zip` 的 NekoTune 构建；本主题与当前工作区的主题功能一同适配。较早的正式版尚无这套接口。

1. 在「设置 → 外观」导入 `build/packages/nekotune.theme-starcape.nktheme.zip`。
2. 点击「星穹 · Starcape」卡片，首次启用确认 QML 信任。
3. 使用「浅色／深色／跟随系统」切换配色。明暗切换保留 Shell 实例。

外观页复用宿主面板。更新 ZIP 后，在卡片点「更新主题包」并确认替换；「重新加载」只重新读取已安装文件，不会安装刚构建的 ZIP。更新及重新加载保留主题选择、显示模式和播放队列。

图标导航栏底部的设置按钮可以进入「外观」并切换回其他主题。`Ctrl+Shift+E` 始终由宿主打开独立恢复窗口；无法交互时用 `--safe-mode` 启动。「恢复默认主题」恢复夜樱，并保留独立扩展配置。

完整 Shell 管理自己的布局。Starcape 继续显示独立扩展页面、设置、工具栏以及已选页面／播放栏替换；切走主题后宿主恢复原来的插槽选择。曲库筛选、歌单和播放来自宿主；网格／列表、滚动位置等主题视图状态在卸载 Shell 后重建。

## 首页与设置功能

1.1.1 对齐当前宿主的首页与设置功能，并保留星空卡片和分组布局：

- 首页可切换「最近入库／最近播放」，显示每周听歌时长、近 30 天热力图和常听歌曲；歌曲菜单支持下一首播放和加入队列末尾。
- 首页和导航栏都能进入听歌历史，使用宿主的时间范围、搜索、完整播放筛选、分页和清空确认功能。
- 设置增加音频引擎（后端、淡入淡出、ReplayGain／响度、均衡器）、播放倍速及重置、音乐库迁移／校验／备份／恢复、迷你模式和桌面歌词。音频输出、扩展设置、AI、数据库位置、外观及动态音乐壁纸入口保留。
- 音频引擎、音乐库、窗口模式、听歌统计和历史页直接复用宿主组件；平台与后端不支持的选项仍显示宿主说明。设置左侧支持滚动，切换分组回到内容顶部。

## 星空音乐壁纸

需要支持 `ui.wallpaper`、`ExtensionApi.wallpaper` 和完整 Shell 壁纸设置入口的当前宿主构建。更新后进入「设置 → 动态音乐壁纸」，把「壁纸样式」切换为「跟随当前主题」，然后启用壁纸。选择主题本身不会自动开启壁纸；已有 1.0.x 安装请通过外观页「更新主题包」安装新的 ZIP。

壁纸复用 Starcape 的星尘、星座、星辉蓝／浅色配色和默认封面，显示当前歌曲、进度及当前／下一句歌词。星座光晕随播放缓慢呼吸；暂停、断线、隐藏、零装饰强度或减少动态效果时停止。静态 Canvas 不逐帧重绘。公共封面背景、模糊和透明叠加仍由宿主绘制；歌词开关、逐字插值频率和装饰强度沿用宿主设置。

横屏、竖屏和紧凑窗口使用自适应布局；主题切换和重新加载沿用宿主窗口，关闭壁纸不会停止播放。

## 制作与打包

源码在 `theme/`，这里只包含允许分发的清单、QML、JavaScript、`qmldir` 和 PNG。开发工具、文档、测试在主题包外。

在本仓库根目录执行 `cmake -S . -B build && cmake --build build`，输出 `build/packages/nekotune.theme-starcape.nktheme.zip`。主题校验在宿主导入时完成。开发时在扩展管理器挂载 `theme`；不要挂载 `starcape` 或整个扩展目录。构建不会修改实际安装和当前主题。

只分享配色可以去掉清单中的 `ui`；在应用中导出本主题会包含完整 QML 和资源。
